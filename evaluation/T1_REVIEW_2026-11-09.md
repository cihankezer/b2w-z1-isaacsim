## Changes verified in code and CPU tests

`standing_ee/kinematics.py` now computes bounds directly relative to each owning
rigid body. The earlier world-AABB-to-local-AABB conversion unnecessarily enlarged
rotated geometry. The visual-only fallback had the same issue and now bounds
individual geometry prims relative to the body as well.

Body AABBs remain a broad filter. Each candidate pair is then checked against
separate collider bounds using all 15 oriented-box separating axes. Ground
clearance also uses each collider separately. This avoids treating empty space
between colliders as solid geometry. The boxes still enclose the actual shapes;
an overlap remains a conservative rejection, not proof of physical penetration.

## Collision geometry investigation

**Verified in the available files:** the eight arm collision primitives are
capsules in the USD, while `robots_usd/z1_gripper_description/urdf/z1.urdf` authors
cylinders. Capsule heights mostly equal those cylinder lengths, with extra
rounded ends. For example, the link00 USD capsule has height approximately
0.051 m, radius 0.0325 m and total axial extent 0.116 m; the URDF cylinder's axial
extent is 0.051 m. The earlier exact capsule calculation found 12.5 mm penetration
between link00 and link02 at the recorded nominal state.

These are not proven identical source versions: link04's USD height is 0.067 m,
whereas the available URDF length is 0.073 m. The URDF therefore does not establish
an exact reconstruction of the intended research robot.

A **diagnostic-only** USD reference layer changes the eight Z1 capsules to
cylinders using the existing USD heights/radii/transforms. It overrides collision
geometry and deinstances Z1 visual/collision groups; visual geometry is unchanged
and the original layers are read-only. No joint frames, limits, gains, mass or inertia properties are authored
by this candidate. The construction script, primitive dimensions and hashes are
retained with it. It has not been installed or used for GPU simulation.

With corrected conservative bounds, this candidate removes the mount and distal
capsule candidates but still returns `self:link03:link05`. Their bounds have an
approximately **4.5 mm separating gap**, smaller than the proposed 5 mm margin.
This is not confirmed physical penetration. Neither the margin nor that pair
was exempted to obtain a pass.

**Unresolved scientific/asset decisions:** confirm the intended arm collision
shape and source version; decide how nominal mechanical clearances should be
represented and checked. A repaired asset or a changed margin would change the
benchmark definition and must be explicitly versioned before target generation.

ID `sha256:b52a521085e561319e84e79e157b8cd8846e1a5089fb946d8e3909f4a6c0f8f4`,
two B2W environments, seed 1101, 0.005 s physics and 0.02 s control intervals.
Repository commit was `1e3069a2a2345841761dc9649d1d811a6d2e0b64`, with uncommitted
T1 sources retained. Containers used unique names, read-only source mounts and
new persistent result/cache directories. No other containers were changed.

**Recorded before shutdown:** all ten component assertions passed on each probe:

- Named 22-action ordering, position targets, forced-zero wheel velocity targets,
  action subset reset, and foot/arm sensor-name mappings.
- Independent USD FK against simulator body frames for **18 states**: nine
  configurations in each of two environments, including translated/rotated bases
  and seeded arm joint configurations. Maximum errors were approximately
  **4.87e-7 m** and **1.21e-6 rad** across all bodies. These were kinematic writes
  and forward updates, not dynamically reachable or collision-free trajectories.
- Finite simulator Jacobians, shape `[2, 34, 6, 28]`.
- Manual subset reset preserved the other environment's episode clock, joint
  state, action and settled reference. Automatic asynchronous resets with a
  surviving environment are still untested.
- Injected cached NaN produced `invalid_state`; NaN was not sent to PhysX.
  Injected base force history produced `collision_contact`; this checks label
  plumbing, not actual collision sensor response to an impact.
- Timeout function distinguished ticks 2999 and 3000. An injected tilt and a
  simultaneous collision/time limit were recorded at the physical terminal
  state before automatic reset. Samples retained separate terminated/truncated
  flags and times 0.02 s and 60 s. This was one control step with injected clocks,
  not a 60 s rollout or an isolated successful timeout.

**Process failure:** the first probe aborted during Python finalization. Scoped
SDK references and explicit garbage collection did not resolve the issue; two
retries segfaulted. The final retry printed both environment-close completion
and application-close completion before the crash. All three exited 1 through
the image's Python wrapper. Their assertions are useful observations, but none
is a clean integration-test pass.

A minimal application-only control and a minimal unstepped T1 environment both
exited **0**. The native failure's cause remains unresolved; these controls do
not establish that production evaluation is affected or unaffected. No exit-code
override, fast-shutdown workaround or dependency change was added.
